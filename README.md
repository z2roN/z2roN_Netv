# z2roN_Net (네트워크 정보 보기) v1.0.0
안드로이드에서 내 네트워크 상태를 한 화면에 보여주는 앱 (Flutter, 플러그인 없음).

- 외부(공인) IP, 국가·통신사
- 연결 방식(무선 Wi-Fi / 유선 이더넷 / 모바일), Wi-Fi 이름(SSID), BSSID, 주파수, 신호 세기, 연결 속도(링크 속도)
- 내 IP, DNS, 게이트웨이(공유기) + [공유기 접속] 버튼(브라우저로 http://게이트웨이 열기)
- 속도 측정: 다운로드 / 업로드 / 응답(핑) (Cloudflare 속도 측정 서버 사용)
- 내 기기: 기기 이름, 제조사/모델, Android 버전(API), 커널
- 같은 네트워크 기기 검색: IP, 이름(공유기가 알려주는 경우), 종류·운영체제(열린 포트로 추정)
- 빌드: .github/workflows/build.yml (GitHub Actions, APK)

## 한계
- 안드로이드는 다른 기기의 MAC 주소·운영체제를 직접 알려주지 않아 운영체제는 '추정'입니다.
- Wi-Fi 이름은 위치 권한을 허용하고 휴대폰 위치 기능이 켜져 있어야 보입니다.
- 공유기가 기기 간 접속을 막으면 기기 검색에 나오지 않을 수 있습니다.
